# Sistema de Microservicios de Libros

## Objetivos

1. Implementación de un sistema que permita la inserción y lectura de datos de libros en distintas bases de datos.
2. Registrar todos los accesos mediante Swagger.

---

## Casos de Uso

1. Registrar un libro
2. Consultar un registro del sistema
3. Consultar un libro

---

## Registrar un libro

1. Registrar el libro en PostgreSQL
2. Registrar el libro en MongoDB
3. Registrar el libro en JSON

---

## Consultar un registro del sistema

1. Consultar un libro por ISBN o por nombre
2. Listar libros por autor
3. Listar libros por nombre
4. Listar libros por fechas de lectura
5. Listar libros por fechas de registro

---

## Consultar libro

1. Debe poder consultarse un libro específico por su ISBN

Resultado:  
Se obtienen todos los datos completos del libro.
